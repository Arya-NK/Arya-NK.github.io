# Arya NK

Personal website and blog built with Jekyll.

## Local Development

```bash
bundle install
bundle exec jekyll serve
```

Visit `http://localhost:4000`

## Tech Stack

- Jekyll 4.3+ / Sass / Ruby 3.x
- GitHub Pages (Actions CI/CD)
- Font Awesome 6 (CDN)
- GLightbox (image lightbox)
- Animate.css (animations)
- Vanilla JavaScript
